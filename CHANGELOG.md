# Changelog

## 0.1.0 — 2026-09-09

First public source release. Packages use the `@cranberry-forge/*` scope and can be installed from locally built archives; they are not published to the npm registry.

### Included

- Twelve independent tools: Biome, Flux, Signal, Satchel, Chatter, Latch, Trailmark, Loom, Wayfinder, Spring, Parcel, and Tempo.
- Two portable games: Mothlight, a narrative adventure, and Afterglow, a survival arena.
- Interactive Three.js workbenches, three minimal examples, TypeScript declarations, tutorials, reproducible gallery renders, and isolated package checks.
- Optional local HTTP companion with an OpenAPI 3.1 description.
- Contributor guidance, security policy, structured issue templates, and a pull-request checklist.
- Public-source disclosure checks and executable README examples.

### Compatibility

Rendering packages target Three.js r180 with WebGLRenderer. APIs are pre-1.0; each package guide documents its supported inputs, snapshot format, ownership rules, and limits. Browser/GPU visual QA and WebGPU support are not claimed.
